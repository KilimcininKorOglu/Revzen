# Revzen

Revzen brings Windows-style taskbar behavior to the macOS Dock.

## Planned features

- Click a Dock icon to minimize all windows of the active app, or to restore them.
- Hover a Dock icon to see a live preview of each window of the app. Click a preview to bring that window to the front.
- Close a window from its preview with the close button or a middle click.
- Window title under each preview.
- Cached preview for minimized windows.
- Scroll over a Dock icon to cycle through the windows of the app.
- Option to show or hide windows from other Spaces.
- Adjustable hover delay, excluded apps list, and launch at login.
- Follows the system light and dark appearance.

## Requirements

- macOS 15 or later
- Accessibility and Screen Recording permissions
